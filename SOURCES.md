# Sources and provenance

The rule data in `data/nasa_rules.json` is a concise Japanese adaptation derived from NASA NPR 7150.2D, Chapters 3–5. It is not represented as NASA certification, endorsement, or an official NASA compliance profile.

Primary source: NASA NPR 7150.2D — NASA Software Engineering Requirements.

The MCP architecture was independently implemented for this project. The public `standards-mcp` project was reviewed as a useful prior-art reference for agent-first, task-routed coding standards and progressive disclosure; this implementation adds additive mid-task scope updates and an evidence-completeness final review gate.

Before public redistribution, re-check source/licensing notices for any additional materials you add. Do not assume third-party material hosted on a U.S. government site is public domain.
